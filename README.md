In modern finance, artificial intelligence (AI) and machine learning, especially reinforcement learning

(RL), offer significant potential for automating decision-making in stock trading. This project

investigates the application of RL techniques particularly Proximal Policy Optimization (PPO) for

stock trading. Our RL agent is designed to dynamically learn and adapt optimal trading strategies in

response to various market conditions. This report covers the complete project lifecycle, from data

processing to model training, evaluation, and analysis of RL algorithms' performances.
